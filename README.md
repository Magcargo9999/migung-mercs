# 미궁 용병단 (가제) — 기술 테스트 빌드

HTML + CSS + JavaScript만으로 돌아가는 용병단 경영 · 미궁 탐험 시뮬레이션.

## 실행

- `index.html`을 브라우저로 열면 된다 (더블클릭, `file://`로도 동작).
- 서버가 필요하면 이 폴더에서 `python -m http.server` 실행 후 `http://localhost:8000`.
- 저장: 브라우저 저장소에 자동 저장된다. 설정 → "저장 내보내기/불러오기"로 텍스트·파일 백업도 할 수 있다.

## 폴더 구조

```
index.html

  assets_manifest.js  도트 좌표·앵커 (tools/build_assets.py가 자동 생성)
  util.js             시드 RNG, 날짜(1년 = 52주 × 7일 = 364일, 10년)
  data.js             스탯 17+3, 종족 12, 직업 15, 특성, 스킬, 아이템, 몬스터, 보스, 시설, 서사, 연간 목표
  items.js            장비 생성·등급·옵션
  merc.js             용병 생성(CA/PA), 파생 능력치, 훈련·성장, 긴장, 부상, 전직
  combat.js           속도 기반 순서제 자동 전투, 지시 수행력, 보스 기믹
  dungeon.js          층 생성, 방 이벤트, 야영 브리핑, 귀환석, 전리품
  world.js            시간 진행, 주간 정산, 모집, 상점·암시장·경매, 의뢰, 라이벌, 연말 평가, 저장
  sprites.js          도트 로딩·그리기 (배치 A 마스크 색 변형)
  battleview.js       전투·탐험 Canvas 연출
  ui.js / main.js     화면(DOM)과 부팅

  batchA/             배치 A 원본 그대로 (32×48 검사 + 마스크 + 이펙트 + 상층부 타일)
  img/                이미지 시트에서 잘라낸 아틀라스 (원본 색 그대로)
```

## 확정 사항 반영

| 항목 | 구현 |
|---|---|
| 턴 방식 | 속도 기반 순서제 (게이지 100 도달 순) |
| 스탯 | CA 대상 17개 (1~20) + 긴장·호전성·부상 빈도(숨김) |
| CA | 직업 가중합 ÷ 1.9 (핵심 5 ×2, 보조 6 ×1, 나머지 6 ×0.5) → 10~200 |
| 명성별 모집 CA | F 10–30 · E 18–40 · D 25–50 · C 40–70 · B 60–90 · A 80–110 · S 100–130 |
| PA | 20 + 180 × (난수 3개 평균), 명성과 무관, CA+5 이상, 나이 많을수록 여유 감소 |
| 주간 성장 | 0.25 × 시설 × 종족 × 직업 × 나이(1.5/1.25/1.0/0.5) × (1+0.02×꾸준함) × (1−CA/PA) × 특성 × 강도(0.7/1.0/1.4) |
| 훈련장 | 1단계 ×1.0·3명 / 2단계 ×1.2·5명 / 3단계 ×1.4·10명, 단계별 훈련 가능 스탯, 전직 장소 |
| 기간 | 10년 (520주), 하루 단위 진행, 주간 정산 |
| 핵심 목표 | 창립 멤버 · 연말 길드 평가(S~D) · 용병 개인 서사 / 라이벌은 압박 장치 |
| 인원 | 파티 최대 6, 로스터 최대 10 (사무소 단계별 6/8/10) |

## 도트 사용처

| 이미지 | 쓰임 |
|---|---|
| 배치 A zip | 검사 전투·탐험 도트(4방향), 머리·옷 색 변형 마스크, 검기 이펙트, 그림자, 상층부 타일 |
| 직업 시트 6장 | 검사·기사·궁수·사제·마법사·도적 전투 도트 (파생 직업도 이 중 하나를 씀) |
| 몬스터 시트 | 거미·해골·해골 궁수·쥐·슬라임 |
| 여왕거미 시트 | 10층 보스, 알 |
| 타일 시트 | 고해상도 바닥·벽·소품 (설정에서 선택) |
| 컨셉 시트 | 20·30·40층 보스, 시설 그림(단계별), 고블린 등 몬스터 아이콘 |
| 외형 규격서 | 검사·기사·도적·궁수 의상 변형 32종 + 자동 생성 샘플 50종 → 비인간 용병 초상화 |
| 인간 시트 6장 | 의상 16세트×4방향 전신 도트 + 머리·피부 마스크, 완성 초상화 32장(+짝 도트 20) → 인간 용병 전부 (아래 설명) |
| 배치 A 개요 | 참고용 (규격 확인) |

## 아직 임시인 부분

- 인간 외 종족 전용 도트가 없어 직업 도트를 공용으로 쓴다 (종족은 글자로만 표시).
- 중층·심층 몬스터 일부와 20·30·40층 보스는 컨셉 시트 그림/아이콘을 대신 쓴다.
- 중층·심층 타일이 없어 상층부 타일에 지역 색조만 입힌다.
- 머리·옷 색 변형은 배치 A 검사에만 적용된다 (제공된 마스크가 있는 도트만). 설정에서 끌 수 있다.

## 설정

- 검사 도트: 배치 A / 이미지 시트
- 초상화: 의상 변형 / 전투 도트와 동일
- 미궁 타일: 배치 A / 고해상도 시트
- 외형 색 변형: 켜기 / 끄기
- 일반 전투 자동 스킵

## 인간 시트 (인간 용병 전용)

`tools/build_human.py`가 시트 6장에서 잘라 `assets/human/`과 `js/assets_human.js`를 만든다.

- 전신: 검사·기사·도적·궁수 각 4벌 × 앞·옆(좌/우)·뒤. 시트의 머리는 갈색·얼굴 없음 상태라서, 용병마다 정해진 초상화의 머리색·피부색으로 머리/피부 영역만 바꾸고 눈·눈썹·입을 작게 그려 넣는다. (설정에서 "원본 색 그대로"로 끌 수 있다)
- 초상화: 시트의 완성 초상화 32장 그대로. 직업 계열(검사/기사/도적/궁수)에 맞는 것 중 하나가 용병마다 고정 배정된다.
- 정지 컷이라 움직임(숨쉬기·돌진·피격·쓰러짐)은 코드로 만든다.
- 시트에 없는 직업은 가장 가까운 계열을 빌린다 (사제→기사 계열, 마법사·정령사·흑마법사→도적 계열의 후드 옷 등).
- 헤어스타일 24종·얼굴 부품(눈·입·수염 등)은 시트 도트가 머리에 구워진 상태라 아직 조합에 쓰지 않았다. 부품만 분리된 시트가 오면 같은 구조로 붙인다.
